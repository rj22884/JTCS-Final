JTCS ERP - Quick Start
======================

Location: E:\Git\JTCS Final

EASIEST WAY
-----------
Double-click: PUSH_AND_DEPLOY.bat
  -> GitHub pe push + VPS pe deploy (ek click)

Ya: JTCS_ERP.bat
  1 = Install (first time)
  2 = Start server
  3 = Stop server
  6 = Edit .env (set MAIL_PASSWORD)
  9 = ONE CLICK Push + Deploy VPS

OR use individual files:
  install_jtcs_erp.bat  - first-time setup
  start_jtcs_erp.bat    - run server on port 8000
  stop_jtcs_erp.bat     - free port 8000
  push_to_git.bat       - commit + push to GitHub
  deploy_to_vps.bat     - SSH to VPS and git pull update

GIT + VPS DEPLOY
----------------
1. Local Windows: double-click push_to_git.bat
   (or JTCS_ERP.bat menu option 7)
2. First time only: copy deploy_vps.env.example -> deploy_vps.env
   set VPS_HOST / VPS_USER / VPS_PATH
3. Local Windows: double-click deploy_to_vps.bat
   (or JTCS_ERP.bat menu option 8)

Manual on VPS (if SSH deploy not set):
  cd ~/JTCS-final
  bash scripts/vps_pull_update.sh
  # then restart app / use python3 on Ubuntu

First time on a new VPS:
  cd ~/JTCS-final
  bash scripts/vps_first_setup.sh
  # sets up python3 venv, .env, and systemd service jtcs-erp

VPS mail check:
  cd ~/JTCS-final/erp
  python3 scripts/test_smtp_health.py
  python3 scripts/check_vps_mail.py
  # .env must have MAIL_PASSWORD + APP_BASE_URL=http://YOUR_IP:8000

TROUBLESHOOTING
---------------
Port 8000 busy     -> run stop_jtcs_erp.bat
Email not sending  -> set MAIL_PASSWORD in .env
Registration error -> admin email already used at /setup; use Login
